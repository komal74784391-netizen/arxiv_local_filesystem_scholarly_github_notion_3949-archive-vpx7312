# arxiv_local_filesystem_scholarly_github_notion_3949-archive-vpx7312

Public mirror of the Vantage Materials Laboratory technical-report archive.

- `archive/screening_queue.tsv` - Q4 2026 screening queue export (planned entries)
- `archive/revision_catalogue.tsv` - authoritative revision catalogue (one row per revision)
- `archive/fulltext_recent.tsv` - rolling full-text index (recent deposits only)
- `bulletin/register.md` - shared bulletin register for the revision audit
- `records/<record-id>/README.md` - canonical record landing page
- `code/<record-id>/` - reference implementation snapshots
- `pdfs/<record-id>/vN.pdf` - snapshot of revision N
- `pdfs/<record-id>/latest.pdf` - convenience copy for multi-revision records
